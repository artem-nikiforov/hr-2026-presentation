# Показ Учебного центра · HR-конференция 2026

Короткий фильм на 3:48, который идёт в браузере сам: 13 сцен, фотографии
и видео, записанная озвучка, инфографика и звук. Собран под проектор
конференции — кадр 16:9, крупная типографика, управление сведено к одной
кнопке.

**Открыть показ:** https://artem-nikiforov.github.io/hr-2026-presentation/

Нажать «Начать показ» — дальше всё идёт само. Пробел ставит на паузу,
`F` разворачивает во весь экран, `]` и `[` подбирают громкость музыки,
`M` выключает её целиком.

## Как запустить локально

```sh
npm start                     # http://localhost:8777/
```

Открывать именно через сервер: со схемой `file://` браузер не отдаст
шрифты и озвучку.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html` | Оболочка: кадр 16:9 и пульт. |
| `assets/scenes.js` | Кадры и промты генерации изображений. |
| `assets/story.js` | Режиссура: реплики, надписи, камера, музыка. |
| `assets/durations.js` | Длительности озвучки, снимаются из MP3. |
| `assets/timeline.js` | Состояния показа и переходы. |
| `assets/player.js` | Контроллер: графика, камера, счётчики, звук, голос. |
| `assets/reveal.js` | Появление текста по буквам (Serega Gentle / Emotional). |
| `assets/sound.js` | Звуковые акценты и музыкальная подложка. |
| `assets/voice.js` | Озвучка с корректной отменой. |
| `assets/presentation.css` | Оформление на токенах дизайн-системы KU Mini. |
| `img/` | Стартовые кадры и видео. |
| `audio/vo/` | Записанная озвучка, по файлу на реплику. |

| `PROMPTS.md` | Задание на генерацию изображений. |
| `VIDEO_PROMPTS.md` | Промты коротких видео и правила подмены фотографий. |

## Команды

```sh
npm test                 # проверки данных, разметки и прогон показа в jsdom
npm run export           # пересобрать PROMPTS.md, prompts.json, манифест озвучки
npm run bump             # обновить версии стилей и скриптов в index.html
node import_voice.mjs    # разложить записи озвучки и снять длительности
```

`npm run bump` стоит запускать перед пушем, если менялись файлы в `assets/`:
GitHub Pages кэширует их на десять минут, и без новой версии браузер
какое-то время будет показывать старую сборку.

Источник правды — модули в `assets/`. `PROMPTS.md` и `prompts.json`
собираются из них, руками не правятся.

## Как заменить фотографию видео

Положить рядом файл с тем же именем и расширением `.mp4`:
`img/s01_bite.jpg` → `img/s01_bite.mp4`. Показ подхватит его сам.
Подробности и промты — в [`VIDEO_PROMPTS.md`](VIDEO_PROMPTS.md).

## Шрифты и права

Golos Text и Montserrat — SIL OFL.

**Flame — проприетарный фирменный шрифт.** В `mini-ds/README.md` он помечен
как предназначенный только для внутреннего использования. Он опубликован
здесь по прямому решению владельца проекта; если это решение изменится,
достаточно убрать `mini-ds/fonts/Flame-*.otf` и объявления `@font-face`
в начале `assets/presentation.css` — заголовки перейдут на Golos Text.

`deslop/` — сторонний набор инструментов ([mishanaer/deslop](https://github.com/mishanaer/deslop)),
включён как рабочая копия. Показу для работы не нужен: реализации эффектов
текста перенесены в `assets/reveal.js`.

Фотографии сгенерированы нейросетью по правилам из `VISUAL_REF/`
и не являются съёмкой реальных ресторанов.
