# Звуковые акценты

Короткие звуки, привязанные к моментам сценария. Файла нет — играет
синтезированная замена, показ не молчит.

## Что стоит записать

Синтез эти звуки не вытягивает:

| Файл | Сцена | Что искать |
| --- | --- | --- |
| `crunch.mp3` | 1 | укус бургера, хруст булки, 0,5–1 с |
| `rewind.mp3` | 1 → 2 | перемотка плёнки, 0,5–1 с |
| `cricket.mp3` | 4 | одинокий сверчок, комедийная пауза, 1,5–2,5 с |
| `bricks.mp3` | 10 | кладка кирпича или игровой «level build», 1–2 с |
| `tada.mp3` | 6 | фанфара-тадам, 1–1,5 с |

## Что уже звучит синтезом

`tick`, `step`, `scratch`, `swipe`, `nosignal`, `handoff`, `cash`, `snap`,
`sparkle`, `liftoff`, `rocket`, `beat`, `mosaic`, `warm`.

`snap` — щелчок мышеловки. Если синтезированный покажется слабым, сюда
хорошо ляжет запись «mousetrap snap» или «wood snap».

Любой можно заменить: положить файл с тем же именем и расширением `.mp3`.

## Требования

MP3, моно, 0,2–2 секунды, тишина по краям обрезана. Громкость выставлена
в коде — нормализовать не нужно.

Полный список с источниками — в [`../../SOUND.md`](../../SOUND.md).
