# Звук показа

Три папки, три разные роли.

```
audio/
├── music/    музыкальная подложка — сквозной луп на весь показ
├── sfx/      короткие акценты: хруст, скретч, касса
└── vo/       озвучка, уже разложена (node import_voice.mjs)
```

Показ звучит и без `music/` и `sfx/`: акценты играют синтезом, музыки
просто нет. Каждый добавленный файл заменяет собой заглушку — код при
этом не меняется.

Что именно искать и где брать — в [`../SOUND.md`](../SOUND.md).
