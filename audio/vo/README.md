# Озвучка

Реплики закадрового голоса — по одному файлу на реплику, имя = `id` из
`manifest.json` (`s01_1.mp3`, `s04_2.mp3` и так далее).

Пока файла нет, страница озвучивает реплику синтезом речи браузера на
русском — чтобы можно было прогнать тайминг до готовой озвучки.

Формат: MP3, моно, 128 kbps, без «хвостов» тишины по краям.

## Если заменяете запись вручную

Положили новый файл прямо в `audio/vo/` — **обязательно выполните**:

```sh
node import_voice.mjs
```

Команда пересчитает длительности в `assets/durations.js` по фактическим
файлам. Без этого показ будет отводить реплике старое время и обрежет её
или оставит лишнюю паузу. Файлы, которые вы положили вручную, команда не
затирает: она копирует из папки студии только то, что там новее.

Чтобы браузер не играл закэшированную старую запись, после замены
выполните ещё и `npm run bump` — он обновит метку сборки, которую показ
добавляет к путям озвучки, музыки, звуков и роликов.
