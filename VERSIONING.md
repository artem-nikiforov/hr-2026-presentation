# Сохранённая версия проекта

Локальный репозиторий создан 6 сентября 2026 года.

- Базовый коммит: `1b7b96d`.
- Тег: `baseline-before-motion`.
- В снимке 574 файла: обе HTML-версии, 16 изображений, шрифты, исходный XLSX, промпты, визуальные правила и содержимое `deslop/`.
- Служебные `.DS_Store`, временный файл Excel и внутренние каталоги `.git` в снимок не включены.
- `deslop/` сохранён обычными файлами, не ссылкой на подмодуль. Его собственный вложенный репозиторий на диске не изменён. Историей вложенного репозитория управляют отдельно; общая точка отката содержит его рабочие файлы.

## Посмотреть сохранённую версию

```sh
git log --oneline --decorate
git show --stat baseline-before-motion
```

## Открыть исходную версию рядом с текущей

Выполнить из корня проекта:

```sh
git worktree add --detach ../conference-baseline baseline-before-motion
```

Это создаст соседнюю папку с сохранённой презентацией, не затрагивая текущие изменения. В ней можно открыть `index.html` или запустить локальный сервер для воспроизведения ресурсов.

## Продолжить работу от исходной версии

Если рабочая папка чистая (`git status --short` ничего не выводит), создать отдельную ветку:

```sh
git switch -c restore-baseline baseline-before-motion
```

Новые коммиты на прежней ветке сохранятся. Несохранённые изменения сначала оформить отдельным коммитом; принудительный сброс для обычного возврата не нужен.

План улучшения находится в `IMPROVEMENTS.md` и сохранён после базового снимка отдельным коммитом.
