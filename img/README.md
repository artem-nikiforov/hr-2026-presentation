# Стартовые кадры

Сюда кладутся сгенерированные кадры под именами из `../PROMPTS.md`
(`s01_bite.jpg`, `s02a_storage.jpg` и так далее). Пока файла нет, страница
показывает заглушку с названием кадра и ссылкой на промт — ничего не ломается.

Формат: 16:9, JPG, длинная сторона от 1920 px. Без читаемого текста в кадре.

Когда кадры заменят на видео: положить `s01_bite.mp4` рядом и поменять
`<img>` на `<video muted playsinline>` в сборке сцены (`index.html`, функция
построения DOM).
