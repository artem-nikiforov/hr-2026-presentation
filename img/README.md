# Стартовые кадры

Сюда кладутся сгенерированные кадры под именами из `../PROMPTS.md`
(`s01_bite.jpg`, `s02a_storage.jpg` и так далее). Пока файла нет, страница
показывает заглушку с названием кадра и ссылкой на промт — ничего не ломается.

Формат: 16:9, JPG, длинная сторона от 1920 px. Без читаемого текста в кадре.

## Видео

Ролик кладётся рядом с фотографией под тем же именем: `s01_bite.jpg` →
`s01_bite.mp4`. Показ подхватит его сам, править код не нужно; удалили файл —
вернулась фотография.

Формат: 1920×1080, H.264, 25 fps, без звука. Ролик играет один раз и замирает
на последнем кадре, поэтому он не должен быть короче времени своей реплики.

Промты и длительности — в `../VIDEO_PROMPTS.md`.
