# KU Mini · бренд-фундамент

Облегчённая версия дизайн-системы KU: **только цветовые токены и корпоративный
шрифт**. Без компонентов, интерактивов, SCORM и служебных отступов. Для
**экспериментальных, непотоковых** проектов, где нужен фирменный вид, но не
нужна вся машинерия курсов.

Папка `mini/` самодостаточна — скопируй её целиком в проект.

## Подключение

```html
<link rel="stylesheet" href="ku-mini.css">
<html lang="ru" data-audience="bk-base">
```

Дальше верстай что угодно, опираясь на токены `--ku-*` — цвета и шрифт будут
фирменными, остальное на твоё усмотрение. Демо всех токенов — `index.html`
(открой через `python3 -m http.server`).

## Что внутри

- `ku-mini.css` — один файл: шрифты (@font-face) + флюидный корень +
  мини-reset + палитра + семантические токены + подразделы.
- `fonts/` — Flame (бренд), Golos Text и Montserrat (оба SIL OFL).

## Переключение бренда («переодевание»)

Один-два атрибута в корне перекрашивают проект и меняют шрифт:

```html
<html data-audience="bk-base">                     <!-- Flame + Golos, пламя -->
<html data-audience="ms" data-direction="lyudi">   <!-- Montserrat, бирюза/розовый -->
<html data-theme="dark">                            <!-- тёмная тема (кроме МС) -->
```

Направления МС: `inzh · lc · restoran · lyudi · produkty · stancii · king-avto`.

## Основные токены

```
--ku-brand / -strong / -press / -soft / -ring   акцент и оттенки
--ku-contrast / --ku-contrast-on                 второй цвет + текст на нём
--ku-grad-brand / -grad-brand-soft               градиенты
--ku-brand-on                                    текст поверх бренд-заливки
--ku-bg / -surface / -surface-2 / -card          поверхности
--ku-text / -soft / -muted                       текст
--ku-border / -border-soft / -divider            линии
--ku-success / -danger / -warning / -info (+ -soft)   функциональные
--ku-viz-1…5                                     серии для графиков
--ku-font-display / --ku-font-body               шрифты
```

Оттенки, кольцо фокуса и градиент **выводятся** из `--ku-brand` +
`--ku-contrast` — своей теме достаточно задать два цвета.

Локальный акцент в БК-базе: класс `.ku-tint-ember|sky|green|amber|ink` на
блоке перекрашивает его в другой фирменный цвет.

## Связь с полной ДС

Имена токенов **совпадают** с полной версией (в корне репозитория), поэтому
разметку и стили легко переносить между mini и полной ДС. Нужны компоненты,
интерактивы, SCORM-курсы — бери полную версию.

## Лицензии

Golos Text, Montserrat — SIL OFL. **Flame — проприетарный фирменный шрифт**:
только для внутреннего использования, не публиковать вовне.
