# Конфетти

Показ рисует конфетти сам, на canvas, в фирменных цветах — ничего класть
не обязательно. Это работает без сети и без сторонних библиотек, поэтому
на конференции не подведёт.

## Если хочется готовую анимацию Lottie

Положить файл сюда:

```
assets/lottie/confetti.json
```

и подключить проигрыватель в `index.html` перед `assets/confetti.js`:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/lottie-web/5.12.2/lottie.min.js"></script>
```

Показ сам увидит файл и сыграет его вместо своих частиц. Нет файла или
не загрузился проигрыватель — молча остаются частицы.

Внимание: подключение с CDN добавляет зависимость от интернета. Для зала
надёжнее скачать `lottie.min.js` в `assets/` и сослаться на локальный файл.

## Где брать

- **lottiefiles.com/free-animations/confetti** — большая подборка,
  скачивается как Lottie JSON или dotLottie, прозрачный фон. Бесплатно
  для коммерческого использования по Lottie Simple License.
- **github.com/zzerodesigns/lottie-animations** — репозиторий с готовыми
  Lottie JSON.
- **github.com/heniczyna/lottiefiles_confetti_example** — минимальный
  пример подключения конфетти через Lottie Web Player.

Брать вариант с прозрачным фоном и одиночным проигрыванием, без петли:
конфетти должно осыпаться один раз и закончиться.
